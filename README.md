# step_semester_3
# OOP Class Problems

This repository contains solutions to Object-Oriented Programming (OOP) class problems implemented in Java.

## Problems Included

The following Java programs are included:

- `Course.java`
- `IdCard.java`
- `MessWallet.java`
- `PlacementRecord.java`
- `Student.java`

## Concepts Used

These programs demonstrate fundamental Object-Oriented Programming concepts in Java, including:

- Classes and Objects
- Attributes and Methods
- Constructors
- Encapsulation
- Object creation and usage
