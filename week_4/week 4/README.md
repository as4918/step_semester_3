## Week 4 Topics

This week reinforces the same basic constructs used in Week 3:

-   `for` loops
-   arrays / parallel arrays
-   `if-else`
-   arrays of objects
-   constructor overloading
-   `this()` constructor chaining
-   `this` keyword
-   `final` methods
-   static blocks
-   inheritance and `instanceof`
-   type casting

## Practice Programs

The practice set contains 5 problems:

1.  **Library Book Cataloguing** --- `this()` constructor chaining and
    `PENDING` default.
2.  **Payroll Batch Bonus Round** --- `this` keyword in constructor and
    method.
3.  **Late Fees --- Skip the On-Time Accounts** --- `final` methods and
    `if-else`.
4.  **One-Time College Setup, Many Students** --- static block.
5.  **Account Batch Payments** --- `instanceof` with different account
    types.

## Assignment Problems

The assignment set contains the same five ideas with different
scenarios:

1.  **Hackathon Registration** --- constructor overloading and `this()`
    chaining.
2.  **Canteen Inventory** --- `this` keyword.
3.  **Parking Overstay Fine Calculator** --- `final` methods.
4.  **Library Membership Card Setup** --- static block.
5.  **Canteen Payment Dispatch** --- inheritance, `instanceof`, casting,
    and a running total.

## Recommended Order

Do each practice problem first, then the matching assignment:
